팀의 화면·서버 코드를 기반으로 기능을 합쳤다. 캐릭터의 콘텐츠별 스타일과 화면 크기 대응을 유지하면서 작품별 저장 레시피와 성숙한 얼굴 표현을 함께 적용했다. 기존 팀원과 외부 라이브러리의 기여를 새 저장소의 단독 창작으로 주장하지 않는다.

이 저장소에는 실행 소스·정적 자산·DB 스키마·핵심 문서·기존 회귀 검사 코드를 남겼다. 로컬 비밀 설정, DB 덤프, 개인 독서 기록, 평가 원문 스냅샷, 브라우저 프로필, 이전 화면 목업과 불필요한 검증 캡처는 복사하지 않았다. 기존 배포를 자동 변경하는 GitHub 워크플로우도 옮기지 않았다.

원본 코드와 포함된 자료의 권리·이용 조건은 그대로 존중한다. 이 정리는 임의의 새 오픈소스 라이선스를 부여하지 않는다.
