# Explore 콘텐츠 정책 (저작권)

결정일: 2026-11-18. 이전 상태: "다운로드 저작권 정책 미결정".

## 결정

- Explore(3.0/3.1)에는 **책의 저자(권리자)가 직접 등록하고 권리 확인을 마친 콘텐츠만** 노출함.
- 해당 콘텐츠는 **구매를 통해서만** 받을 수 있음. 무료 받기·다운로드 버튼 없음.
- 구매한 콘텐츠는 구매자 본인 서재에 책으로 추가되고, 본인만 열람함. 복제·재배포·공유 기능 없음.
- 이용자가 업로드한 콘텐츠와 그 파생물(요약·관계도·문항·캐릭터 관련 콘텐츠)은 Explore에 노출하거나 다른 이용자에게 전달하지 않음.

## 근거

- 이용자 업로드 콘텐츠를 제3자가 받는 구조는 공중송신권(저작권법 제18조)·배포권(제20조) 침해와 서비스의 방조 책임 위험이 가장 큼. 저작권법 제104조의 특수한 유형의 온라인서비스제공자로 평가될 위험도 있음.
  - 저작권법: https://www.law.go.kr/법령/저작권법
  - 대법원 2007. 1. 25. 선고 2005다11626 판결(P2P 서비스 운영자 방조 책임)
- 권리자가 직접 등록·판매하면 이용허락 주체가 명확함.
- 상세 분석: 프로젝트 파일 `legal/저작권_법적리스크_분석.md` (법률 자문 아님).

## 화면·데이터 계약

| 항목 | 내용 |
| --- | --- |
| 3.0 목록 | `GET /api/explore/contents` — 서버는 `authorVerified=true` 항목만 반환. 관심 분야 우선, 최근 등록 순 |
| 3.1 상세 | `GET /api/explore/contents/:id` — 저자 인증 배지, 가격, 이용 범위(`license`) 표시 |
| 3.2 구매 시트 | `POST /api/explore/contents/:id/purchase` `{ method, agreed: true }` — 이용 범위 동의 필수. 성공 시 서재에 책 추가, `Book.purchase`에 주문 정보 기록 |
| 재추가 | 구매한 책을 서재에서 지우면 구매 내역은 유지되고 결제 없이 다시 추가 가능 |
